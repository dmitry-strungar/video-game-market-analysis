# Дашборды игровой аналитики 

## Описание проекта
Интерактивные дашборды в Tableau для анализа продаж видеоигр, трендов жанров и эффективности платформ.  
Проект помогает выявить ключевые драйверы выручки, популярные жанры и региональные различия рынка для поддержки бизнес-решений в игровой индустрии.

## Бизнес-контекст

Издателю видеоигр необходимо понять:

- Какие жанры игр генерируют наибольшую выручку
- Какие платформы доминируют в разных регионах
- Как меняются тренды продаж со временем
- Какие игры и издатели показывают наилучшие результаты

Анализ поддерживает стратегию формирования портфеля, маркетинговый фокус и приоритизацию платформ.

## Цели

- Проанализировать глобальные и региональные продажи игр
- Определить наиболее эффективные жанры и платформы
- Сравнить продажи по регионам (NA, EU, JP, Other)
- Выявить долгосрочные тренды продаж
- Определить топ-игры и издателей по выручке

## Функциональность дашборда

Дашборды Tableau включают:

- Общий обзор продаж
- Продажи по платформам
- Продажи по жанрам
- Сравнение продаж по регионам
- Рейтинг топ-игр
- Анализ временных рядов релизов и продаж

Интерактивные фильтры позволяют анализировать данные по:

- Году  
- Платформе  
- Жанру  
- Региону  
- Издателю  

## Аналитический подход

- Агрегация показателей продаж
- Измерительный анализ по жанрам, платформам и регионам
- Анализ трендов во времени
- Ранжирование лучших результатов
- Интерактивное визуальное исследование данных в Tableau

## Ключевые инсайты

### Структура жанров

- Жанры Action и Shooter доминируют в продажах PS4 в Северной Америке, формируя более 60% выручки.
- Shooter демонстрирует наибольшую среднюю выручку на игру (~0.75 млн).
- Sports занимает третье место (~17-18%), однако сегмент характеризуется доминированием крупных франшиз.
- Нишевые жанры (Strategy, Puzzle, Simulation) формируют минимальную долю выручки.

### Региональное распределение

- Северная Америка (~284 млн) и Европа (~271 млн) являются крупнейшими рынками.
- Совокупно они формируют более 70% глобальных продаж.
- Япония (~93 млн) - меньший по объему, но структурно отличающийся рынок.

### Динамика платформы

- PS4 - лидирующая платформа поколения (~288 млн глобальных продаж).
- Пик продаж пришелся примерно на 2015 год (~42 млн в Северной Америке).
- При планировании релиза необходимо учитывать жизненный цикл платформы.

### Особенности рынка

- Распределение продаж неравномерное: небольшое число игр формирует значительную долю выручки.
- Корреляция между оценками критиков и продажами слабая (R² ≈ 0.17).
- Коммерческий успех зависит не только от качества продукта, но и от маркетинга, силы бренда и тайминга релиза.

## Стек ИИ-инструментов
В процессе работы над проектом использовались AI-инструменты для ускорения разработки и повышения эффективности аналитики:

ChatGPT применялся для:
1) Генерации черновиков вычисляемых полей для расчёта средней выручки на игру по жанрам и платформам, а также ранжирования топ-издателей по глобальным продажам
2) Прототипирования логики сравнения региональных продаж (NA, EU, JP, Other) и расчёта долей каждого региона в общем объёме рынка
3) Поиска идей для визуализации жизненного цикла платформ (совмещение временных рядов продаж с фильтрацией по поколениям консолей)

DeepSeek применялся для:
1) Доработки и оптимизации табличных вычислений (проверка корректности расчёта накопительных итогов по годам, устранение ошибок при фильтрации по регионам)
2) Проверки логики выявления корреляции между оценками критиков и продажами (расчёт R-квадрат, интерпретация слабой связи)
3) Подготовки описания ключевых инсайтов для документации дашборда (структурирование выводов по жанровым трендам, региональным различиям и жизненному циклу платформ)

Все ключевые этапы - проектирование структуры дашборда, настройка фильтров, визуализация и интерпретация результатов - выполнены самостоятельно. AI использовался как инструмент для ускорения разработки и проверки гипотез.

## Технологический стек

- Tableau
- Excel
- Визуализация данных  
- Разведочный анализ данных

## Как использовать

1. Скачайте файл `.twbx` из папки `dashboards`
2. Откройте его в Tableau Desktop или Tableau Public
3. Используйте фильтры для интерактивного анализа данных

## Ограничения

- Анализ основан только на исторических данных о продажах
- Данные о поведении пользователей отсутствуют
- Не учитываются данные о маркетинговых расходах и ценообразовании
- По некоторым платформам количество наблюдений ограничено
